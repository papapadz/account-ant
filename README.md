# Account-Ant

> Automated accounting ledger for enterprise fund management, chart of accounts, and journal transactions — packaged as a native desktop app.

Account-Ant is a self-contained desktop application that runs entirely on the local machine. There is no cloud dependency, no external server, and no subscription. The backend is a Laravel 12 API served by NativePHP's embedded PHP runtime; the frontend is a Nuxt 4 + Ionic Vue SPA that communicates with it over localhost.

---

## Features

| Module | What it does |
|--------|-------------|
| **Dashboard** | At-a-glance summary of fund balances and recent transactions |
| **Ledger Accounts** | Create and manage the chart of accounts with status tracking |
| **Account Items** | Define debit/credit line items and link them to ledger accounts |
| **Ledger Entries** | Post transactions with debit/credit amounts, posting dates, and fund allocation |
| **Fund Accounts** | Track fund balances and attach funds to projects |
| **Projects** | Group ledger entries and funds under a project |
| **Journal** | View the full journal of posted entries |
| **Management — Accounts** | Manage the chart of accounts hierarchy |
| **Management — Funds** | Create and review fund account definitions |
| **Management — Items** | Manage account items shared across the system |
| **Settings** | Company profile, personal profile, and affiliation management |
| **Roles & Permissions** | Spatie permissions with `super_admin` / `admin` roles |

## Architecture

```
account-ant/
├── src/
│   ├── backend/          # Laravel 12 PHP application (NativePHP desktop)
│   │   ├── app/          # Models, controllers, providers
│   │   ├── config/       # nativephp.php, app.php, …
│   │   ├── database/     # Migrations (35+), seeders
│   │   ├── nativephp/    # Electron wrapper generated by NativePHP
│   │   └── routes/       # api.php (REST), web.php (SPA catch-all)
│   └── frontend/         # Nuxt 4 + Ionic Vue SPA
│       └── app/
│           ├── pages/    # index, ledgers, projects, settings, management/*
│           ├── components/
│           ├── composables/
│           └── layouts/
```

**Runtime flow:**

```
Electron window
  └── NativePHP (embedded PHP 8.3 runtime)
        └── Laravel 12 backend  ←──API──→  Nuxt SPA (served as static HTML)
                  └── SQLite (local app-data directory)
```

## Local Development

### 1. Clone the repository

```bash
git clone <repo-url> account-ant
cd account-ant
```

### 2. Set up the backend

```bash
cd src/backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --force
php artisan db:seed
```

### 3. Set up the frontend

```bash
cd ../frontend
npm install
```

### 4. Run in development mode

From `src/backend`, start both the NativePHP desktop app and the Vite dev server together:

```bash
composer run native:dev
```

This runs:
- `php artisan native:run` — starts the Electron shell with the embedded Laravel server
- `npm run dev` — starts the Nuxt/Vite dev server the Electron window connects to

Alternatively, run them separately:

```bash
# Terminal 1 — backend
php artisan native:run

# Terminal 2 — frontend
cd ../frontend && npm run dev
```

## Building the Desktop Installer

From `src/backend`:

```bash
php artisan native:build
```

This will:
1. Run `prebuild` scripts (`php artisan optimize:clear`)
2. Bundle the Laravel app + PHP runtime into an Electron wrapper
3. Run `postbuild` scripts (`php artisan native:migrate:fresh --seed --force`) to pre-seed the bundled SQLite
4. Produce a Windows NSIS installer (`.exe`) in `nativephp/electron/dist/`

> **First-boot seeding:** On the end-user's machine, the `NativeAppServiceProvider` runs `migrate` on every boot and seeds the database automatically on first install (when the `roles` table is empty).

### Customising the app icon

Replace `src/backend/nativephp/electron/build/icon.png` with your own logo (minimum **256×256 px**, square PNG). For Windows, you can also supply `icon.ico` for sharper taskbar icons.

## Database

Account-Ant uses **SQLite**, managed entirely by Laravel migrations. The database file lives in the OS app-data directory when running as a packaged desktop app.

### Seeders

| Seeder | What it seeds |
|--------|--------------|
| `RolesSeeder` | `super_admin` and `admin` roles with permissions from `config/bee.php` |
| `WorldAddressSeeder` | Regions, sub-regions, countries, states, cities |
| `HrSeeder` | Initial HR / person records |
| `DeviceInfoSeeder` | Device registration info |

Run seeders manually:

```bash
php artisan db:seed
```

---

## Authentication

- Token-based via **Laravel Sanctum** (`/api/login`, `/api/logout`, `/api/me`)
- All API routes behind `auth:sanctum` middleware
- Roles enforced at the controller level using Spatie Permission

### Default credentials (after seeding)

> Credentials are set by `HrSeeder`. Check `database/seeders/HrSeeder.php` for the default admin email and password.

## Configuration

Key environment variables in `src/backend/.env`:

| Variable | Description |
|----------|-------------|
| `APP_NAME` | Application display name (`Account-Ant`) |
| `APP_KEY` | Laravel encryption key |
| `APP_ENV` | `local` / `production` |
| `APP_DEBUG` | Enable detailed error pages |
| `NATIVEPHP_APP_VERSION` | Installer version string |
| `NATIVEPHP_APP_ID` | Reverse-domain app identifier |
| `NATIVEPHP_APP_AUTHOR` | Displayed author |
| `NATIVEPHP_UPDATER_ENABLED` | Enable/disable auto-updater |
| `NATIVEPHP_UPDATER_PROVIDER` | `github` / `s3` / `spaces` |
